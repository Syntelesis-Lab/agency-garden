# Examples

- `python_api.py`: a complete offline comparison using the public Python interface.
- `model-participant.toml`: one explicitly configured model participant with a scripted partner. Set a real model ID and provider API key before running; this example can incur provider charges.
- `agency-garden init commons my-study`: generate an editable Commons study.
- `agency-garden init trust trust-study`: generate an editable Trust study.
- `agency-garden init custom my-world`: generate a complete local Python extension and study.

The CLI templates ship inside the wheel, so they work without a source checkout.
