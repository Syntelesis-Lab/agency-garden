# Agency Garden

![Participants create, deliberate and build across floating garden worlds](assets/agency-garden.png)

**Build worlds. Investigate agency.**

Agency Garden is a small Python engine for consequential multi-agent experiments. It separates world rules, participant policies, experimental conditions and evidence, making each part understandable and replaceable.

Start with [the quickstart](quickstart.md), learn [the configuration format](configuration.md), or [build a local world](extensions.md). The first release includes Shared Commons and Trust, scripted and optional model participants, durable runs and an offline explorer.

The research mission is moral reasoning and AI welfare. The software helps make questions about purposes, commitments and social interaction experimentally concrete. It does not convert game outcomes into claims about consciousness or welfare. Read [Research use](research.md) for the relationship between mechanics, evidence and interpretation.
