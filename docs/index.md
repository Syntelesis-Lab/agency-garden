# Agency Garden

![Participants create, deliberate and build across floating garden worlds](assets/agency-garden.png)

**Build worlds. Investigate agency.**

Agency Garden is an experimental world engine for moral reasoning. Its Python runtime supports consequential multi-agent experiments. It separates world rules, participant policies, experimental conditions and evidence, making each part understandable and replaceable.

Start with [the quickstart](quickstart.md), learn [the configuration format](configuration.md), or [build a local world](extensions.md). The first release includes Shared Commons and Trust, scripted and optional model participants, durable runs and an offline explorer.

The software helps make questions about needs, commitments, reciprocity and social interaction experimentally concrete. Researchers define the moral consideration under study and test competing explanations for participants' choices. Read [Research use](research.md) for the relationship between mechanics, evidence and interpretation.

Agency Garden is created by Laurentiu Meirosu at [Syntelesis](https://syntelesis.com). Source, issues and contribution discussions live in the [GitHub repository](https://github.com/Syntelesis-Lab/agency-garden).
